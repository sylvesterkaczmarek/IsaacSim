# Changelog

## [1.0.0] - 2026-07-14
### Added
- Initial release. The protobuf message schemas (`Clock`, `Image`, `Pose`, `JointStates`, `JointCommand`, `UpdatePrimAttribute`) and their generated C++/Python bindings, split out of `isaacsim.zmq.core` into a dedicated `isaacsim.zmq.protos` extension.
